## API interface omission (`api_interface_omission`) — 5 row(s)

**Observed cause:** The first-pass api.types list omitted SOAP; The current official SOAP API guide identifies SOAP API and lists supported editions/permissions.

**Prevention:** Enumerate separately documented interfaces and webhooks/SOAP/GraphQL/SDK distinctions; do not assume the REST guide is the complete API surface.

## API scope/detail completeness change (`api_scope_detail_added`) — 5 row(s)

**Observed cause:** Expand the API detail to include the directly documented additional interface and avoid leaving a corrected type unexplained.

**Prevention:** Add an interface-completeness checklist to supplemental API review and ensure `api.types` changes are reflected in `api.details` with their exact limits.

## Authentication-method omission (`auth_method_omission`) — 1 row(s)

**Observed cause:** Attio's directly opened authentication guide supports OAuth 2.0, workspace API keys, Bearer tokens, and HTTP Basic (token as username, blank password). The first pass omitted Basic.

**Prevention:** Inspect the dedicated authentication guide and enumerate every documented wire-level method (including alternate HTTP authorization schemes) before normalizing the list.

## Bounded MCP-search limitation clarified (`bounded_search_limitation_documented`) — 2 row(s)

**Observed cause:** Clarify that the unknown comes from bounded discovery and is not a NOT_FOUND determination.

**Prevention:** Use bounded-scope language for inconclusive official searches and keep UNKNOWN unless authoritative evidence supports availability or a scoped NOT_FOUND classification.

## Credential-path conflation (`credential_path_conflation`) — 2 row(s)

**Observed cause:** Attio's official pricing page lists API/MCP on the Free tier and says no credit card is required; its hosted MCP uses user OAuth. The API-key path remains admin-only. The first-pass ADMIN_APPROVAL_REQUIRED label conflated the API-key route with all supported access paths.

**Prevention:** Model API-key, OAuth/MCP, and admin-issued paths separately; determine the record-level self-serve label from all viable documented paths rather than one credential route.

## Credential-path nuance added (`credential_path_nuance_added`) — 1 row(s)

**Observed cause:** The earlier blocker could imply admin-key issuance is required for all integrations. The first-party MCP OAuth path is user-authorized; admin approval applies to workspace API keys.

**Prevention:** Write blockers per access path and distinguish OAuth user authorization from API-key issuance/admin controls.

## MCP access constraint omitted (`mcp_access_constraint_omitted`) — 1 row(s)

**Observed cause:** The first-pass blocker did not state the external ChatGPT subscription requirement or app-install permission documented by Pipedrive.

**Prevention:** Capture provider-account app-install permission and external client-plan requirements as distinct constraints; label which company owns each gate.

## MCP announcement/current-state conflict preserved (`mcp_announcement_conflict_preserved`) — 1 row(s)

**Observed cause:** The initial details omitted a first-party server announcement. The later current official material inspected describes client use; it does not establish whether the announced server EAP is currently available. Preserve this conflict and UNKNOWN status.

**Prevention:** Track announcement dates and current setup pages side by side; an announced future/early-access feature remains UNKNOWN until current endpoint/setup is directly documented.

## First-pass MCP false negative / unresolved value (`mcp_false_negative`) — 3 row(s)

**Observed cause:** The Amazon-owned repository directly documents a Local MCP for SP-API educational example. It establishes an available local MCP sample, not a hosted supported product. The first pass left status UNKNOWN because targeted MCP discovery was incomplete.

**Prevention:** Add a targeted first-party MCP discovery checklist and inspect first-party repositories/indexes; distinguish local examples, hosted products, and unsupported samples in separate fields.

## MCP product-versus-sample scope omission (`mcp_scope_omission`) — 1 row(s)

**Observed cause:** The raw first pass left MCP unclassified and its details said no first-party status was assigned. The official Amazon-owned repository now documents a local educational MCP example; product-versus-sample scope must be explicit.

**Prevention:** Separate MCP presence from product support/hosting and credential requirements; quote repository caveats in the claim rather than collapsing them into a single availability label.

## outbound_webhook_capability_clarified (`outbound_webhook_capability_clarified`) — 2 row(s)

**Observed cause:** Clarify the directly documented outbound webhook automation while retaining REST as the API type and explicitly avoiding an unsupported claim of a standalone Webhooks API.

**Prevention:** Review examples in the full error table.
